Se você tem a imagem hospedada online:

1. Copie a URL completa da imagem
   Exemplo: https://i.imgur.com/abc123.jpg

2. No HTML, linha ~410:

   ┌────────────────────────────────────────────────────┐
   │ background:url('https://i.imgur.com/abc123.jpg')   │
   │   center/cover no-repeat;                          │
   └────────────────────────────────────────────────────┘

 💡 DICAS PARA BOA IMAGEM DE FUNDO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Use foto quadrada ou vertical
✓ Resolução mínima: 1080x1080
✓ Formato: JPG ou PNG
✓ Tamanho: menos de 2MB (para carregar rápido)
✓ Foto com boa iluminação
✓ Evite fotos muito claras (texto fica difícil de ler)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 🎨 AJUSTAR FILTROS DA IMAGEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Linha ~411, você pode ajustar:

filter:blur(4px) brightness(0.22) saturate(0.5);

┌──────────────────────────────────────────────────────┐
│ blur(4px)          → Desfoque (0-10px)               │
│ brightness(0.22)   → Brilho (0.1-1.0)                │
│ saturate(0.5)      → Saturação (0.1-2.0)             │
└──────────────────────────────────────────────────────┘

Exemplo - imagem mais clara:
filter:blur(4px) brightness(0.35) saturate(0.5);

Exemplo - imagem mais escura:
filter:blur(4px) brightness(0.15) saturate(0.5);

Exemplo - mais colorida:
filter:blur(4px) brightness(0.22) saturate(0.8);

Para ver qual imagem fica melhor:

1. Mude a imagem
2. Salve (Ctrl+S)
3. Recarregue o navegador (F5 ou Ctrl+R)
4. Não gostou? Mude de novo

💡 Teste 2-3 opções antes de decidir!

Se usar IMAGEM LOCAL:

Ao publicar online (Netlify/GitHub), você DEVE:

1. Fazer upload do HTML
2. Fazer upload da IMAGEM também
3. Ambos na mesma pasta

Exemplo no Netlify:
- Selecione HTML + JPG juntos
- Arraste os dois de uma vez


Se usar LINK ONLINE:

Não precisa fazer upload da imagem, só do HTML.
